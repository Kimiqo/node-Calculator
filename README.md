# Node.js Calculator

A simple terminal-based calculator application built with Node.js, demonstrating the use of built-in (readline), third-party (chalk), and custom modules (both CommonJS and ES Modules).

## Features
- Built-in Module: Uses readline for capturing user input from the terminal.
- Third-party Module: Uses chalk for colorful console output (e.g., green for results, red for errors).
- Takes user input for two numbers and an operation (+, -, *, /).
- Validates input and handles errors (e.g., invalid numbers, division by zero).
- Outputs results in a user-friendly format with color styling.

## Custom Modules:
- operations.js (CommonJS): Handles addition and subtraction
- advancedOperations.mjs (ES Modules): Handles multiplication and division.
